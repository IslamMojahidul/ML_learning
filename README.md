📂 Repository Structure

The code is organized as I progress through different concepts and topics:

basics/: Fundamental concepts including variables, data types, operators, and basic input/output.

control_flow/: Conditional statements (if, elif, else) and loops (for, while).

functions/: Reusable blocks of code, parameters, return values, and scope.

data_structures/: Working with lists, dictionaries, tuples, and sets.

projects/: Small, practical projects combining multiple concepts.
